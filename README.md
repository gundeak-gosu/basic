# 타임라인 리플레이

구글 타임라인 데이터를 기간별로 지도 위에서 **영상처럼 재생**하고,
**장소 + 반경**을 지정하면 그 근처에 **언제 몇 시에 방문했는지** 찾아주는 웹페이지입니다.

`index.html` 파일 하나로 동작합니다. 브라우저로 열기만 하면 되고, 위치 파일은 서버로 업로드되지 않습니다.

## 기능
- **파일 불러오기**: 새 Timeline.json(안드로이드), 아이폰 내보내기 파일, 예전 Takeout(Records.json, 월별 Semantic JSON, .zip)
- **단계별 흐름**: 가져오기 → 날짜 선택 → 미리보기 → 방문 찾기 → 내보내기(동영상 MP4/WEBM 저장: 480p·720p·정사각·세로)
- **방문 기록 검색**: 지도 클릭 / 주소·장소명 입력 / `위도, 경도` 입력 → 반경(m) 안의 방문을
  도착·출발 시각과 체류 시간으로 표시. 결과를 누르면 그 시각부터 재생, CSV로 저장 가능
- **샘플 데이터**: 내 파일이 없어도 가상의 일주일 데이터로 체험

## 실행
- `index.html`을 더블클릭해서 열거나
- GitHub Pages로 배포: 저장소 Settings → Pages → 브랜치 선택
