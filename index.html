타임라인 파일

내보낸 타임라인 파일을 선택하세요. 파일은 이 기기 안에서만 처리되고 어디에도 업로드되지 않습니다.

타임라인 파일 가져오는 방법
  1. 휴대전화 설정에서 위치를 여세요.
  2. 위치 서비스 → 타임라인을 차례로 선택하세요.
  3. 타임라인 데이터 내보내기를 누른 다음 계속을 누르세요.
  4. JSON 파일을 저장한 다음 여기로 돌아와 선택하세요.
  1. Google 지도 앱에서 프로필 사진 → 내 타임라인을 여세요.
  2. 오른쪽 위 ⋯ → 위치 및 개인 정보 보호 설정을 누르세요.
  3. 타임라인 데이터 내보내기를 누르고 파일 앱에 저장하세요.
  4. 여기로 돌아와 저장한 JSON 파일을 선택하세요.

예전 Google Takeout 위치 기록(.zip, Records.json, 월별 JSON)도 읽을 수 있습니다. 컴퓨터에서는 먼저 휴대전화의 파일을 옮겨 주세요.

컴퓨터에서는 파일을 여기에 끌어다 놓아도 됩니다
